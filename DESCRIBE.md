# Date Command — Modrinth draft

**Title:** Date Command
**Description:** Replies with today's date and day of the week.
**Command:** `/date`

## Body

Replies with today's date and day of the week.

### Usage

`/date` — run in game chat (OP level 0 / everyone can use it).

### Installation

1. Install Forge 47.4.20 for Minecraft 1.20.1
2. Drop the jar into your `mods` folder
3. Type `/date` in chat
